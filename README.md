# HWandHAII
Information for HWandHAII authors:

## CEURART Template
We intend to publish the workshop proceedings via CEUR-WS so all camera-ready papers need to be in the CEURART format.

- For Latex-fluent authors, the recommended way is via Overleaf:
    - [https://www.overleaf.com/latex/templates/template-for-submissions-to-ceur-workshop-proceedings-ceur-ws-dot-org/hpvjjzhjxzjk](https://www.overleaf.com/latex/templates/template-for-submissions-to-ceur-workshop-proceedings-ceur-ws-dot-org/hpvjjzhjxzjk)
- For Word/LibreOffice users, an ‘approximation’ of the template is available:
    -  [https://ceur-ws.org/Vol-XXX/CEUR-Template-1col.odt](https://ceur-ws.org/Vol-XXX/CEUR-Template-1col.odt)
    - This template requires the Libertinus font family installed. Installation guidance for Linux, Windows and macOS users is included in the template file.
- We are happy to assist with anyone having problems with the templates!
